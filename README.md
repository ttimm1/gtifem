# ФЭМ · Расписание

Telegram Mini App с расписанием занятий факультета экономики и менеджмента
СПбГТИ(ТУ). Данные — с открытого сайта <https://gtifem.ru/dekanat/raspisanie/>.

- **Приложение:** <https://ttimm1.github.io/gtifem/>
- **Бот:** [@spbgti_raspisanie_bot](https://t.me/spbgti_raspisanie_bot)
- **Данные:** обновляются дважды в день: 06:30 и 12:30 МСК через GitHub Actions
- **Бот живёт** на Cloudflare Workers (бесплатно, без домашнего компьютера)

## Что внутри

| Экран | Что показывает |
| --- | --- |
| Сегодня | текущая/следующая пара, обратный отсчёт, расписание дня |
| Неделя | 7 дней, переход по неделям |
| Всё | календарь на семестр + пары выбранного дня |
| Ещё | группа, тема, 8 палитр, напоминания, обновление |

Групп — 43 (бакалавриат, магистратура, СПО), данные на семестр вперёд.

## Структура

```
docs/        сайт (GitHub Pages: main /docs) + data/*.json
tools/       скрапер сайта, иконки, предпросмотр вёрстки
bot/         Cloudflare Worker + деплой
.github/     ежедневное обновление расписания
```

Подробности и грабли — в [docs/HANDOFF.md](docs/HANDOFF.md).

## Локальный запуск

```bash
python3 -m http.server 8899
open "http://127.0.0.1:8899/docs/?group=6611"
```
